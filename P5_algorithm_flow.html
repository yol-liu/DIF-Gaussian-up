P5 算法总览：GT-Conditioned CVAE（稀疏视角锥束 CT 重建）

模型：DenseProbabilisticDIFGaussian（mode='gt_cvae'）· 配置：prob-gt-cvae.yaml · 主代码： dense_probability.py · latent_np.py · model.py。 详细参数含义与调参方向见 P5_algorithm_structure.md 第 5、6 章。

一、训练链路（GT 条件化，S=1 个后验样本）

实线箭头 前向数据流　虚线箭头 分布/损失流　红色系 GT 特权分支（仅训练使用，部署丢弃）　金色 目标函数

二、部署链路（prior_mc_mean，N=8 个先验样本）

部署时丢弃 GTEncoder 与后验头，latent 从稀疏先验 p(z|C) 采样；N 个样本逐个解码后做 Welford 在线聚合： 均值 = 重建预测，样本间方差 = 不确定性图（predictive variance）。

三、真实训练日志趋势（DIFG-6v_1031_1655，max step=147800）

数据来自 logs/DIFG-6v_1031_1655/step_metrics.jsonl 的 8 个真实快照（step = 0 / 200 / 400 / 5000 / 15000 / 40000 / 90000 / 147800）。 观察要点：β 前 500 步线性升温至 0.02；L_volume 快速下降后低位平台；真实 KL 2.8 → 28.3 上升但未达地板； KL_effective 恒 = 32.0（= 64×0.5 free-bits 地板），当前 KL 约束主要来自地板而非真实 KL； q_g_std 0.500 → 0.231 后验逐步收缩（确定性增强），p_g_std 0.500 → 0.531 基本持平（先验方差稳定）。

始终低于地板（约束主要由地板提供）； 若 raw 触顶/稳定则后验已逼近先验，可考虑减小 free-bits 或增大 β。

数据来源：logs/DIFG-6v_1031_1655/step_metrics.jsonl（8 个真实快照；中间曲线为 SVG 折线线性连接）。
