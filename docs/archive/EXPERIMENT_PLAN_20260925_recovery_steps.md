## 2. 所有新训练的统一约束

### 2.1 不复用权重

- 全部从随机初始化开始；不传 `common_init`、`warm_start`、`resume`、`resume_path`，不加载最佳模型、公共初始化或蒸馏reference。
- 每次固定Python/NumPy/Torch seed，记录模型初始状态及构造后的RNG状态。原T1-nomax的seed0初始状态SHA256为 `021d532c1d5d5ddf51cdd32402f04f982b3d0280a99f41217a77ee319281fe7f`。
- 训练进程保留禁止 `torch.load` / `torch.serialization.load` 的检查；优化器也重新建立。
- 本次实验自己产生的checkpoint可以在训练结束后做离线评估，但不能作为另一轮训练的初始化。长训练从零一次跑完，不用现有不精确的mid-epoch resume拼接。
- 相同seed不保证不同结构的共有参数相同：必须核对共有参数初始哈希。不一致时标注“结构及初始化同时变化”，不声称纯结构归因。若后续实现按模块独立RNG初始化，作为新协议并重跑双方，仍不读取旧权重文件。

### 2.2 原T1-nomax协议

| 项目 | 设置 |
|---|---|
| 模型 | UNet；anchor geometry Transformer，mean token init、无max residual；point max；12³ anchors |
| 归一化与loss | 原BN、MSE；没有 `model.probabilistic` 字段；`latent.use_latent=false` |
| 几何 | legacy坐标、detector采样；view_update、anatomy、teacher、ray关闭 |
| 数据 | LUNA16，train738 / eval50 / test100；根目录 `/media/wyin/Expansion/Data/LUNA16/C2RV-CBCT/data` |
| 视角 | 固定6 views `[0,8,16,25,33,41]`；无random_views、paired_views或view dropout |
| 优化 | AdamW lr=2e-4；backbone wd=0.01、融合模块wd=0；global clip=1；FP32、batch1、1024 queries、workers2 |
| 调度 | `epoch=400`，每epoch StepLR gamma=`(1e-3)^(1/400)`；延长updates时不随意改变epoch参数 |
| 短预算 | 2000 updates；1000/2000步验证；主比较固定2000步，不挑中途最好checkpoint |
| 复现评价 | 原6例及原顺序，scale1.0，chunk65536；与最新从零训练的病例列表一致 |
| 新批次记录 | 各arm统一 `manifest_steps=总updates`（短跑2000、长跑10000）、`diag_every=25`；记录源码/config/env、初始化、输入摘要、优化器分组、耗时和显存 |
| 输出与运行 | 同一3090串行；名称含版本/seed/repeat/协议hash；不覆盖旧目录 |

完整输入日志会增加同步操作，因此A阶段两个版本统一采用这套记录协议。最近22.8892那次只有前20步记录，保留作参考，不混入A阶段新批次的重复样本统计。数据清单至少记录实际读取文件的内容哈希，元信息和病例列表单独保存；环境或数据变化必须明确标注。

### 2.3 评价与统计

- 主指标：逐病例PSNR、unclipped MSE；同时报告3D SSIM、clipping fraction、边界误差、物理梯度误差、同显示窗切片/误差图。
- SSIM上升不能替代PSNR恢复，也不把SSIM变化一概当作截断伪影。需要时补统一body mask诊断，保留全体积主表，GT mask仅用于评分。
- 分开报告同seed重复波动、不同seed波动、病例间差异。6个病例不是6次独立训练。
- **取消“基线与一次复跑的差值=噪声地板”的晋级规则。** 已有0.1–0.8 dB的描述不是通用显著性门槛。
- A阶段每版本5次用于初步看分布：列出每次结果、均值、标准差、范围、达到历史参考值的次数。不用最好一次替代平均表现，不凭5次就声称明确因果。
- 正式确认按seed报告病例平均差值；病例配对区间仅作补充，不替代训练重复。证据不足写 `INCONCLUSIVE`。

## 5. B阶段：GPU非确定性与误差放大

| ID | 实验 | 预算与输出 | 通过标准 |
|---|---|---|---|
| B-OP | 固定features/grid/upstream，检查grid_sample前向及feature/grid梯度 | 同进程20次、独立进程至少3次；覆盖边界、越界、重复采样 | 各backend单列哈希和最大误差；已有开关失败结果作已知对照 |
| B-DET | 可重复反向累加实现或真正可重复的backend | **待实现；先算子正确性与性能测试** | 对CPU参考预设FP32前向atol1e-6/rtol1e-5、梯度atol1e-5/rtol1e-4；同backend重复逐位一致；覆盖真实形状和坐标范围 |
| B-GRAPH | 真实模型、相同初始状态与输入，完整训练10步 | 3独立进程，共30步 | prediction、gradient、BN、更新后状态逐位相同；不相同则继续查其他算子 |

不能只设置确定性标志就宣布成功。算子替换即使数学等价也可能改变数值轨迹，不保证回到历史23.1。若完整确定性代价过高，允许以明确记录的非确定性协议和多次重复继续研究，不让该问题永久阻塞其他实验。GPU任务仍串行。

## 6. C阶段：训练预算与少量优化因素

### C-L：先看学习曲线

使用A阶段确定的基线，**从零一次训练到10000步**；验证节点1000/2000/5000/10000，`epoch=400`调度不变。先seed0，必要时补seed1、2，总上限30000步。不能从现有partial checkpoint接着训练冒充从零曲线。

主曲线用原6例。训练后可加载本次新生成的checkpoint评估完整50例eval，6例/50例分表。训练预算增加带来的收益，不称为算法提升。

记录train loss、eval PSNR/MSE/边界、clip比例、BN running统计、Gaussian特征跨anchor方差和梯度裁剪比例。训练下降但eval恶化时优先查泛化；两者持续改善时确认2000步是否不足。

### C-O：有诊断依据后最多选两个因素

| ID | 唯一变化 | 目的与实现 |
|---|---|---|
| C-LR | lr 2e-4→1e-4 | 检查过大更新；现有 `--lr` 支持 |
| C-CLIP | clip 1→5 | 检查长期强裁剪；**需新增显式参数**，当前为硬编码 |
| C-Q | queries 1024→4096 | 检查query采样噪声；现有 `--num_points` 支持，但相同步数的query预算增加4倍，不能称完全输入配对或等计算量 |

基线及最多2个变体各2次seed0、2000步，上限6 runs/12000步。先按诊断选因素，不同时改lr、clip、query。C-Q若有收益，再单列同总query预算对照才能主张效率提升。改超参数的结果不称严格复现原配方。

## 8. E阶段：跨seed确认与最终评估

只保留C/D阶段最多2个候选及必要直接对照。seed0/1/2，各自从零10000步；不同底座必须分别保留comparator。

- 主表固定最后10000步、完整50例eval。可另列预先规定的best-eval结果，不按病例/指标换checkpoint。
- 每个seed单列病例平均ΔPSNR、MSE、SSIM、边界/梯度和成本；不把150个“seed×病例”当150次独立训练。
- 工程筛选门槛预登记为：平均ΔPSNR至少+0.10 dB，3个seed方向均正，平均unclipped MSE不恶化，边界/梯度平均恶化不超过2%。**这不是统计显著性保证**；SSIM异常下降须解释。
- 证据不确定时最多给双方各seed加一次重复，不不断换seed直到成功。少于3个seed只算初筛。
- 共享一个基线时上限3 arms×3 seeds×10000=90000步；独立底座和额外重复另算。
- 冻结结构、超参数、初始化与checkpoint规则后，再评估test100，不用test选参。输出同窗切片、误差图和推理成本。

“质量提升”和“质量相当但更稳定/更省算力”分开命名；后者需单独登记非劣与成本标准。

## 9. P阶段：概率路线独立保留，暂缓批量训练

前提是先有可信plain基线。概率代码/config/日志保持独立，不修改冻结基线；`probabilistic.mode: deterministic` 不是原plain。当前实现使用GN/anchor IN处理C/D统计，不意味着概率建模数学上必须采用这一归一化。

| 顺序 | 实验 | 核心对照 |
|---|---|---|
| P-NORM | BN+原采样；GN/anchor-IN+原采样；GN/anchor-IN+嵌套采样 | 无latent、统一MSE，拆开归一化与采样 |
| P-ANCHOR | 相同GN/采样，只把anchor IN换成PointChannelNorm | 复核空间特征差异收缩问题 |
| P-LATENT | 同一底座上无latent、dense mean-code、dense NP | latent净效应，不和不同归一化的plain直接归因比较 |
| P-USAGE | prior latent mean、MC mean S4/S8、oracle posterior、换病例z/zero-z、KL与跨病例方差 | oracle是特权诊断，不是部署成绩；区分观测噪声与latent方差 |
| P-LOCAL | 诊断支持继续后再做global/local latent | 不预先展开beta/sigma/样本数/视角数大网格 |

oracle增益不足0.1 dB时，只能写“本预算未观察到足够的latent利用”，不直接断言信息严格为零；结合无latent对照和换z诊断判断。GT-CVAE、Gaussian NLL、混合视角数留作后续候选，不混入原6-view复现。

冻结参考蒸馏需要加载训练权重，**不属于当前不复用权重的范围**，旧计划该项本轮不执行。概率路线内部有效后，还须与同时训练的plain比较部署质量与成本。

## 10. 下一批任务、预算与交付

估时依据：本机3090上最近2000步加两次6例验证约678秒（11.3分钟）。新算子、更多queries、不同encoder和50例评估成本需实测。下表不是一次性启动全部阶段的指令。

A阶段保留每轮的1000/2000步完整checkpoint及最终partial权重，10轮预计需要约10–15 GB工作空间，另留输出余量。保留已有历史记录，不通过删除旧结果腾空间或覆盖同名run。后续长训练和更多验证节点另算磁盘预算。

| 顺序 | 任务 | 新增训练预算 | 进入下一批的条件 |
|---|---|---:|---|
| 0 | 补runner、冻结记录、零权重加载检查 | 两版本各5步smoke，按改动补测试 | 初始化/输入/分组一致 |
| 1 | A-I/A-B各5次 | **20000步，约1.9 GPU小时**，另加准备 | 先提交版本分布报告 |
| 2 | B算子与短测，必要时A-D | A-D每轮8000步；B-LONG通过门槛后6000步 | 未验证算子不进入长跑；无版本差异证据不盲目回退 |
| 3 | C-L先seed0，按诊断选C-O | 首条10000步；C-O最多12000步 | 明确训练预算/优化稳定性问题 |

| 暂缓 | D2大结构扩展、P概率矩阵 | 未分配批量预算 | 前置问题回答后逐项登记 |
